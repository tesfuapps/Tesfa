## ✦ Engineering & Tech Stack

This portfolio is built with a bespoke **Swiss-editorial design system**:

* **Framework:** React 19 + TypeScript
* **Build Tool:** Vite 6
* **Styling:** Tailwind CSS v4 + Vanilla CSS Custom Tokens
* **Typography:** `Archivo` (Display) & `Space Grotesk` (Body / Monospace accents)
* **Features:**
  * 🌓 Instant Dark / Light mode toggle with persistent local storage
  * 🏷️ Filterable project gallery (`All`, `Branding`, `Packaging`, `Digital`, `Logo Design`)
  * 🔍 Deep case study modals with asset previews and technical specifications
  * 📄 CV modal with isolated print stylesheet (`@media print` clean 1-page layout)
  * 📥 Guaranteed PDF download handler with proper MIME typing and filename retention

## ✦ Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/tesfuapps/Tesfa.git

# 2. Navigate to project root
cd Tesfa

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
